# Agentic Use Case Studio (code app)

React + TypeScript + Vite source for the **Agentic Use Case Studio** Power Apps code app.

**You don't need to build this to use the accelerator.** The compiled app ships inside the
`AgenticUseCaseIntake` solution (`packages/`). Import the solution and open the app. This folder is
here so you can read, change and redeploy it.

## Structure

```
src/
  App.tsx                 app shell: navigation, Reviewer workspace / Submit an idea areas
  components/             Overview, Matrix, Inbox, Detail (with review panel), Submitter, shared UI
  dataverse.ts            data layer: generated Dataverse services only (no fetch/axios)
  domain.ts               choice values, labels and colours for sams_usecase / sams_usecasesystem
  config.generated.ts     intake agent link and guide links, written by scripts/deploy_code_app.ps1
  generated/              services generated by `pac code add-data-source`
  theme.ts, icons.tsx     light/dark theme and Microsoft logo (same look as the Document Processing accelerator)
```

## Change and redeploy

Prerequisites: [Power Platform CLI](https://aka.ms/pac/install), Node.js 22+, Python 3.10+ with
`azure-identity`, and the solution already imported into the target environment.

```powershell
cd code-app
npm install
cp power.config.example.json power.config.json      # then set your environment id
pac code init -n "Agentic Use Case Studio" -env https://<your-env>.crm.dynamics.com/ -b dist
pac code add-data-source -a dataverse -t sams_usecase
pac code add-data-source -a dataverse -t sams_usecasesystem
cd ..
.\scripts\deploy_code_app.ps1        # reads env vars -> writes src/config.generated.ts -> build -> pac code push
```

`deploy_code_app.ps1` reads the environment variables `sams_IntakeAgentUrl`, `sams_ToolGuideUrl` and
`sams_CreditsGuideUrl`, and bakes them into the build. Set `DATAVERSE_URL` and `TENANT_ID` (or a
`.env` file at the repo root, see `.env.example`) before you run it.

For local development, run `npm run dev` and open the *Local Play* URL printed by the Power Apps Vite plugin.

## Data sources

All Dataverse access goes through the generated services in `src/generated`:

- `sams_usecase` (`sams_usecases`)
- `sams_usecasesystem` (`sams_usecasesystems`)
