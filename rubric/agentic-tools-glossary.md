# Agentic tools glossary (plain language)

Use this glossary to explain Microsoft's agentic tools to non-technical people. Source: the "Which agentic tool should I use?" guide (Microsoft Learn guidance, July–August 2026). Guide: https://blue-hill-0cabcc90f.5.azurestaticapps.net/which-agentic-tool.html

## Microsoft 365 Copilot — "Assist me in the flow of work"
Copilot inside Word, Excel, PowerPoint, Outlook and Teams. It helps one person with quick questions, drafting, summarizing and analysis. Nothing to build. Needs a Microsoft 365 Copilot licence per user. Examples: meeting recap with owners and follow-ups; explaining a variance in a workbook; the Researcher and Analyst agents.

## Copilot Cowork — "Delegate outcomes across Microsoft 365"
You hand Copilot a longer, multi-step job across email, calendar, Teams and files, and it comes back with a finished result, even while your device is closed. Needs Microsoft 365 Copilot plus usage-based Cowork billing. Examples: build a quarterly business review deck from email and files; an overnight competitive brief; clear an inbox backlog with drafted replies.

## Agent Builder (declarative agent) — "Create a focused, reusable helper"
A no-code helper built inside Microsoft 365 Copilot from instructions plus knowledge (SharePoint, files, websites). It answers questions for a stable, narrow topic and doesn't take actions. Free for web-only knowledge; using company data needs a Microsoft 365 Copilot licence or metered credits. Examples: onboarding buddy; expense and travel policy Q&A; brand voice checker.

## Copilot Studio – Standard harness — "Control the conversation and workflow"
The classic Copilot Studio agent. Makers design topics, flows and connectors so the agent follows consistent steps and can take actions in business systems. It can be published to Teams, websites and other channels, including for external users. Free to build and test; runtime uses Copilot Credits, except for Microsoft 365 Copilot-licensed employees in Microsoft 365 channels. Examples: IT help desk that resets passwords and raises tickets; leave-request bot in Teams; public website FAQ.

## Copilot Studio – GitHub Copilot harness — "Automate adaptive business processes"
The newer Copilot Studio runtime with a continuous reasoning loop, skills, memory and a sandbox for working with documents. Best when the process varies case by case, involves many documents, or needs several tools with detours and exceptions. Credits are used for building, testing and running, for every user. Examples: draft an RFP response from past proposals; invoice and contract exception handling; vendor due-diligence review that outputs a summary deck.

## Microsoft Foundry — "Build a custom agent product or platform"
A professional developer platform for building agents into your own products at scale: multi-agent systems, custom models, special protocols, strict network isolation, or offline use with Foundry Local. Costs are Azure consumption (models, tools, hosting), not Copilot Credits. Examples: customer-facing support agent inside your product; multi-agent claims intake → adjudication → payout; offline field assistant.

## No agent needed — Power Automate / workflow
If the steps are always the same and need no understanding of language or judgment, a regular automated workflow is simpler and cheaper. Examples: copy attachments to SharePoint and notify a channel; nightly data sync; approval routing with fixed rules.

## Copilot Credits in one paragraph
Copilot Credits are the single unit that measures agent usage, pooled across the organization. What you pay depends on where the agent is built, what it does (a classic answer is 1 credit, a generative answer 2, company-data grounding adds 10, an action 5), the knowledge it reaches, and whether users have a Microsoft 365 Copilot licence.
